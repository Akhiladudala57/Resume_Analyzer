# AI Resume Analyzer

An intelligent AI-powered web application that analyzes resumes, evaluates ATS compatibility, identifies skill gaps, and provides personalized recommendations to help users build professional, recruiter-friendly resumes.

## 🌐 Live Demo

**Website:** https://ai-resume-analyzer-p-85bv.bolt.host

---

## 📖 About the Project

AI Resume Analyzer is designed to assist students, fresh graduates, and professionals in enhancing their resumes through Artificial Intelligence. The application evaluates resume content, generates an ATS (Applicant Tracking System) score, identifies missing keywords and skills, and provides actionable recommendations to improve employability and increase the chances of getting shortlisted.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/akhilachowdary457/Resume-analyzer.git
```

Navigate to the project directory

```bash
cd Resume-analyzer
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```
